# Nihongo Steps — Sentence Practice

Web latihan bahasa Jepang dengan alur belajar bergaya aplikasi latihan bahasa. Fokusnya **kalimat lengkap**, bukan tebak arti satu kata.

## Cara kerja
- Soal berupa kalimat Jepang atau Indonesia.
- Pilihan jawaban juga berupa **kalimat lengkap**.
- Mode Jepang → Indonesia, Indonesia → Jepang, atau campur.
- Jumlah soal dapat dipilih sampai 100.
- Ada progress, XP, nyawa, feedback benar/salah, dan daftar soal yang perlu diulang.
- Tidak menggunakan sound.

## Data
`kotoba.json` adalah data kosakata yang diberikan pengguna dari materi Rikai N5. `sentences.json` berisi 100 kalimat latihan orisinal yang disusun menggunakan kosakata tersebut. Kalimat di `sentences.json` **bukan kutipan kalimat dari PDF**.

## Menjalankan
Buka folder ini di VS Code lalu jalankan `index.html` dengan Live Server.
